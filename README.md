# Твой ноут — сайт tvoy-nout.by
Живой сайт: https://tvoy-nout.by

Статический сайт сервиса по ремонту ноутбуков, компьютеров, телевизоров и планшетов в Минске (две точки: ул. Уманская, 53 и проспект Пушкина, 67).

## Структура

- `index.html` — единственная страница сайта
- `style.css`, `seo.css` — стили
- `script.js` — плавная прокрутка по якорным ссылкам
- `assets/` — логотипы и favicon
- `robots.txt`, `sitemap.xml` — для поисковых систем

## Как открыть

Сборка не нужна: откройте `index.html` в браузере. Либо запустите локальный сервер:

```
python -m http.server 8000
```

и откройте http://localhost:8000/.
